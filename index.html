FinTrack — Expense & Bill Manager

Simple, private expense tracking with local storage, optional Firebase sync and reliable bill reminders.

What it does

  • Track income, expenses, accounts and categories
  • Bill reminders using local notifications / platform alarm
  • Local-only guest mode and optional Google Sign-In + Firebase sync
  • Cross-device sync via Firestore (per-user namespace)
  • Small codebase using Provider architecture (AppState central orchestrator)
Main entry: lib/main.dart · State: lib/providers/app_state.dart
View README Quickstart

Privacy

The app uses Firebase Authentication (Google Sign-In) and Firestore for optional cloud sync. Crash reports are sent to Firebase Crashlytics. The app does not access bank accounts or cards — it stores only data you enter.

See the full privacy policy: privacy.html (or .github/privacy_policy.html)

Get the app (build/run)

Clone and run locally:

git clone <repo-url>
cd expense_tracker
flutter pub get
flutter run

Build APK:

flutter build apk

Important files

  • lib/providers/app_state.dart — central sync & notification logic
  • lib/services/local_storage_service.dart — SharedPreferences keys
  • lib/services/firestore_service.dart — Firestore collections under users/<uid>
  • lib/services/notification_service.dart — platform alarm & notification channels
  • lib/screens/permission_setup_screen.dart — permission flow for alarms/notifications

Quickstart for contributors

  1. Install Flutter SDK & required platform tooling.
  2. Run flutter pub get.
  3. To test migrations and notifications run on an Android device/emulator (alarm APIs require device).
  4. Firebase config: ensure lib/firebase_options.dart exists and platform service files are present (android/app/google-services.json / iOS plist) when using cloud features.

Tests: flutter test (project has basic widget tests).
